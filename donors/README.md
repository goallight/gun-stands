# Donor models

STLs used by `mode: refit` designs.

`PDP_Stand_V1.stl` is a third-party Walther PDP stand. It is here so the
`walther_pdp` design builds out of the box. **Check the original model's
licence before making this repository public** — many printable models are
non-commercial or no-derivatives, and redistributing the mesh may not be
allowed even though modifying it for your own use is.

If in doubt: delete the STL, add `donors/*.stl` to `.gitignore`, and keep the
design YAML. Anyone with their own copy of the donor can still build it.
